## 2. Runtime config + HMAC secret + auth middleware

- [ ] 2.1 Implement `backend-rs/src/runtime.rs` `RuntimeConfig::from_env() -> Result<Self, String>` and `default_app_dir() -> Result<PathBuf, String>`. Behavior: read `CODOXEAR_APP_DIR` env first (trimmed, non-empty wins); else read `HOME` env and return `<HOME>/.local/share/codoxear`. Both error messages must mention which env var failed. Match `san-tian-dev:backend-rs/src/runtime.rs:262-275`. Mirror the target Python `codoxear/util.py:default_app_dir()` semantics; do NOT replicate the legacy `codex-web` warning (Phase 1 just doesn't need it).
- [ ] 2.2 Implement `pub fn load_or_create_hmac_secret(app_dir: &Path) -> Result<Vec<u8>, String>` in `runtime.rs` (or a new `runtime/auth.rs` submodule if you keep `runtime.rs` < 800 lines). Lifted from `san-tian-dev:backend-rs/src/routes.rs:1398-1427` but moved into `runtime` so handlers stay thin. Behavior: `mkdir_p(app_dir)`; if `<app_dir>/hmac_secret` exists with len ≥ 32, read first 64 bytes and return them; else read 64 bytes from `/dev/urandom`, write to file, `chmod 0o600`. Match Python `codoxear/server.py:751-761` byte-for-byte.
- [ ] 2.3 Implement cookie helpers in `runtime.rs` (or `routes.rs` private helpers): `cookie_name() -> &'static str` returns `"codoxear_auth"`; `cookie_ttl_seconds() -> i64` reads `CODEX_WEB_COOKIE_TTL_SECONDS` (default `30 * 24 * 3600`); `cookie_secure() -> bool` reads `CODEX_WEB_COOKIE_SECURE == "1"`; `cookie_path() -> Result<String, String>` reads `CODEX_WEB_URL_PREFIX` and either returns `"/"` or `"<prefix>/"`. Source: `san-tian-dev:backend-rs/src/routes.rs:1429-1450` and Python `codoxear/server.py:167-173`.
- [ ] 2.4 Implement `pub fn verify_auth_cookie(value: &str, secret: &[u8]) -> bool` in `runtime.rs`. Algorithm: split on `.` → `(payload_b64, sig_b64)`; URL_SAFE_NO_PAD decode each; HMAC-SHA256 with secret, verify_slice(sig); on success deserialize payload as `serde_json::Value`; require `exp` to be `i64` and greater than current unix seconds. Return `true` only if all checks pass. Source: `san-tian-dev:backend-rs/src/routes.rs:1336-1359` and Python `codoxear/server.py:782-801`.
- [ ] 2.5 Implement axum middleware `pub async fn require_public_api_auth(State(state): State<AppState>, request: Request<Body>, next: Next) -> Response` in `routes.rs`. Read `Cookie` header, find `codoxear_auth=<value>`, call `load_or_create_hmac_secret(&state.config.app_dir)`, then `verify_auth_cookie`. On `false` or missing return `(StatusCode::UNAUTHORIZED, Json(json!({"error":"unauthorized"})))` with `Content-Type: application/json; charset=utf-8`. On error from `load_or_create_hmac_secret` return `500` with `{"error":"<message>"}`. Source: `san-tian-dev:backend-rs/src/routes.rs:1279-1322` and Python `codoxear/server.py:8690-8691, 817-822`.
